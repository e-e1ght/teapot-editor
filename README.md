# teapot-agent

teapot-agent는 티팟(teapotchat.com)의 캐릭터 제작 데이터를 **로컬 편집기**와 **Claude Code**에서 직접 편집할 수 있도록 하는 도구입니다.

```
 편집기 (http://127.0.0.1:18765/) ─┐
                                   ├─▶ 허브 (server/hub.js) ◀─WebSocket─▶ 티팟 탭의 유저스크립트 ─▶ 티팟 서버
 Claude Code ─MCP─▶ server/index.js ┘        └ backups/ 자동 백업
```

## 개요

- **허브**는 사용자 PC에서 하나만 실행되는 로컬 서버입니다. 편집기 화면을 제공하고, 브라우저의 티팟 탭과 연결합니다.
- 실제 조회와 저장은 **로그인된 티팟 탭**이 수행합니다. 로그인 정보는 브라우저 밖으로 전달되지 않습니다.
- 유저스크립트는 저장본 조회·생성·저장 기능만 허용합니다. **캐릭터 등록(발행)과 삭제는 차단되어 있습니다.**
- 저장본을 덮어쓰기 전에, 서버에 있던 원본을 항상 `backups/<캐릭터 ID>/` 폴더에 백업합니다.

## 요구 사항

| 항목 | 내용 |
|---|---|
| Node.js | 20 이상 (LTS 버전 권장) |
| 브라우저 | Chrome 또는 Chromium 기반 브라우저 |
| 확장 프로그램 | [Tampermonkey](https://www.tampermonkey.net/) |
| Claude Code | Claude와 연동할 때만 필요합니다 (선택) |

## 설치

### 1. teapot-agent 내려받기

다음 두 방법 중 하나로 내려받습니다. 내려받은 폴더를 이 문서에서는 `<설치 폴더>`라고 부릅니다.

- **ZIP으로 내려받기**: [저장소 페이지](https://github.com/e-e1ght/teapot-editor)에서 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다. 내려받은 ZIP 파일의 압축을 원하는 위치(예: `D:\teapot-agent`)에 풉니다.
- **git으로 내려받기**: git이 설치되어 있다면 원하는 위치에서 다음 명령을 실행합니다. 나중에 업데이트하기가 더 쉽습니다.

  ```bash
  git clone https://github.com/e-e1ght/teapot-editor.git teapot-agent
  ```

### 2. Node.js 설치

1. <https://nodejs.org>에서 **LTS** 버전을 내려받아 설치합니다.
2. 터미널(명령 프롬프트, PowerShell 등)에서 다음 명령으로 설치를 확인합니다. 버전 번호가 출력되면 정상입니다.

   ```bash
   node -v
   ```

   ```bash
   npm -v
   ```

### 3. 의존성(필요한 패키지) 설치

teapot-agent가 실행되려면 몇 가지 Node.js 패키지(WebSocket 통신, Claude Code 연결용 MCP 라이브러리 등)가 필요합니다. 이 패키지들은 저장소에 들어 있지 않으므로, `<설치 폴더>` 안에서 `npm install` 명령으로 한 번 내려받아야 합니다. 설치된 패키지는 `<설치 폴더>\node_modules` 폴더에 저장됩니다.

#### 방법 A. 자동 설치 (Windows, 권장)

`<설치 폴더>`의 **`start-editor.bat`을 더블클릭**합니다. 처음 실행할 때 `node_modules` 폴더가 없으면 필요한 패키지를 자동으로 설치한 뒤 편집기를 엽니다. 인터넷 연결이 필요하며, 설치에는 보통 1분 정도 걸립니다. 이 경우 방법 B는 진행하지 않아도 됩니다.

#### 방법 B. 직접 설치

1. `<설치 폴더>`에서 터미널을 엽니다.
   - **Windows**: 파일 탐색기로 `<설치 폴더>`를 연 뒤, 주소창을 클릭해 `cmd`를 입력하고 Enter를 누릅니다. 해당 폴더 위치에서 명령 프롬프트가 열립니다. (빈 곳을 오른쪽 클릭 → **터미널에서 열기**를 사용해도 됩니다.)
   - **macOS**: Finder에서 폴더를 오른쪽 클릭 → **폴더에서 새로운 터미널 열기**를 선택합니다.
   - 이미 열린 터미널이 있다면 `cd` 명령으로 이동합니다. `<설치 폴더>`는 실제 경로로 바꾸어 입력합니다.

     ```bash
     cd "<설치 폴더>"
     ```

2. 터미널의 현재 위치에 `package.json` 파일이 있는지 확인합니다. (Windows는 `dir`, macOS는 `ls` 명령으로 파일 목록을 볼 수 있습니다.)
3. 다음 명령을 실행합니다. 실행에 필요한 패키지만 설치합니다.

   ```bash
   npm install --omit=dev
   ```

4. 명령이 끝나고 `<설치 폴더>` 안에 `node_modules` 폴더가 생겼으면 설치가 완료된 것입니다.

참고 사항:

- 설치 중에 `npm warn allow-scripts`와 같은 경고가 표시될 수 있습니다. 동작에는 영향이 없습니다.
- `npm`을 찾을 수 없다는 오류가 나오면 Node.js가 설치되지 않았거나, 설치 후 터미널을 다시 열지 않은 것입니다. 2단계를 확인한 뒤 터미널을 새로 엽니다.
- 업데이트로 패키지 구성이 바뀐 경우에도 같은 명령을 다시 실행하면 됩니다.
- 편집기 화면의 라이브러리(`editor/vendor.js`)를 직접 고치려는 개발자만 `--omit=dev` 없이 `npm install`로 개발용 패키지까지 설치합니다(약 650MB). 일반 사용에는 필요하지 않습니다.

### 4. 유저스크립트 설치

1. Chrome에 Tampermonkey를 설치합니다.
2. Chrome의 `확장 프로그램 관리` → Tampermonkey `세부정보`에서 **"사용자 스크립트 허용"**을 켭니다.
3. 아래 [허브 실행과 종료](#허브-실행과-종료)에 따라 허브를 실행합니다.
4. 브라우저에서 <http://127.0.0.1:18765/teapot-agent.user.js>를 엽니다. Tampermonkey 설치 화면이 나타나면 **설치**를 누릅니다.
5. 티팟 캐릭터 제작창을 엽니다. 화면 왼쪽 아래에 표시되는 점의 색으로 연결 상태를 확인합니다.
   - **초록색**: 허브에 연결되었습니다.
   - **회색**: 허브가 실행되지 않았습니다.
6. 처음 연결할 때 Chrome이 "로컬 네트워크 기기에 액세스"를 요청하면 **허용**합니다.

유저스크립트가 업데이트되면 4번 주소를 다시 열어 새 버전을 설치합니다.

## 허브 실행과 종료

편집기와 Claude Code는 모두 허브를 통해 동작합니다. 허브는 `127.0.0.1:18765` 포트를 사용하며, 동시에 하나만 실행됩니다.

### 실행

다음 방법 중 하나를 사용합니다.

| 방법 | 동작 |
|---|---|
| `start-editor.bat` 더블클릭 (Windows) | 허브를 실행하고 편집기 창을 엽니다. 허브는 최소화된 "teapot-hub" 창에서 실행됩니다. 의존성이 설치되어 있지 않으면 처음 실행할 때 자동으로 설치합니다. |
| `npm run editor` | 허브를 실행하고 편집기 창을 엽니다. |
| `npm run hub` | 허브만 실행합니다. 터미널 창을 닫으면 허브도 종료됩니다. |
| Claude Code에서 teapot 도구 사용 | 허브가 꺼져 있으면 백그라운드에서 자동으로 실행합니다. |

허브가 이미 실행 중일 때 `start-editor.bat` 또는 `npm run editor`를 실행하면 새 허브를 띄우지 않고 편집기 창만 엽니다.

- **다른 폴더의 허브**가 이미 실행 중이면(예: teapot-agent를 두 곳에 설치한 경우) 실행 중인 폴더 경로를 안내하고 종료합니다. 먼저 실행 중인 허브를 종료한 뒤 다시 실행합니다.
- `start-editor.bat`으로 실행했는데 편집기가 열리지 않으면 작업 표시줄의 "teapot-hub" 창에서 오류 메시지를 확인합니다. 오류가 있으면 창이 닫히지 않고 유지됩니다.

### 상태 확인

브라우저에서 <http://127.0.0.1:18765/api/status>를 엽니다.

- `"hub":true`가 표시되면 허브가 실행 중입니다.
- `tabs` 항목에는 현재 연결된 티팟 탭 목록이 표시됩니다.
- 페이지가 열리지 않으면 허브가 실행되지 않은 상태입니다.

### 종료

다음 방법 중 하나를 사용합니다.

| 방법 | 비고 |
|---|---|
| `stop-hub.bat` 실행 (Windows) | Claude Code가 백그라운드에서 실행한 허브도 종료할 수 있습니다. |
| `npm run hub:stop` | 운영체제와 관계없이 사용할 수 있습니다. |
| "teapot-hub" 창 닫기 | `start-editor.bat`으로 실행한 경우에만 해당합니다. |

### 재시작

허브를 종료한 뒤 다시 실행합니다. 허브 코드를 수정했거나 연결이 불안정할 때 재시작합니다.

```bash
npm run hub:stop
```

```bash
npm run editor
```

- 편집기 페이지는 허브가 다시 실행되면 자동으로 다시 연결됩니다. 저장하지 않은 편집 내용은 유지됩니다.
- 티팟 탭의 유저스크립트도 몇 초 안에 자동으로 다시 연결됩니다.

## Claude Code 연결

teapot-agent는 MCP 서버(`server/index.js`)를 통해 Claude Code와 연결됩니다.

### 등록 범위

| 범위 | 사용할 수 있는 위치 | 등록 방법 |
|---|---|---|
| 전역 (`user`) | 모든 폴더 | 아래 [전역 등록](#전역-등록) |
| 프로젝트 (`project`) | teapot-agent 폴더 | 폴더 안에 `.mcp.json` 파일 생성 |
| 로컬 (`local`, 기본값) | 등록한 폴더 (본인만) | `-s` 옵션 없이 `claude mcp add` 실행 |

### 전역 등록

다른 폴더에서 작업할 때도 티팟 도구를 쓰려면 전역으로 등록합니다.

1. 터미널에서 다음 명령을 실행합니다. `<설치 폴더>`는 실제 경로로 바꿉니다. Windows에서도 경로 구분자로 `/`를 사용할 수 있습니다.

   ```bash
   claude mcp add -s user teapot -- node "<설치 폴더>/server/index.js"
   ```

   예시 (Windows):

   ```bash
   claude mcp add -s user teapot -- node "C:/Tools/teapot-agent/server/index.js"
   ```

2. 등록 결과를 확인합니다. 목록에 `teapot`이 표시되면 정상입니다.

   ```bash
   claude mcp list
   ```

3. 실행 중인 Claude Code가 있으면 종료한 뒤 다시 시작합니다. 새 세션부터 `teapot_*` 도구를 사용할 수 있습니다.

- 등록을 해제하려면 다음 명령을 실행합니다.

  ```bash
  claude mcp remove -s user teapot
  ```

- 설치 폴더를 옮긴 경우 등록을 해제한 뒤 새 경로로 다시 등록합니다.

### 프로젝트 등록

teapot-agent 폴더에서만 사용하려면 폴더 최상위에 `.mcp.json` 파일을 다음 내용으로 만듭니다.

```json
{
  "mcpServers": {
    "teapot": { "command": "node", "args": ["server/index.js"] }
  }
}
```

### 작성 규칙 스킬

`.claude/skills/teapot-html-jsx/SKILL.md`에는 티팟의 HTML·마크다운 렌더링 규칙과 JSX 보안 검증 규칙이 정리되어 있습니다.

- teapot-agent 폴더에서 Claude Code를 실행하면 스킬로 자동 인식됩니다.
- 다른 폴더에서 MCP로만 연결된 경우에도, Claude는 연결 시 안내에 따라 `teapot_rules` 도구로 같은 내용을 읽습니다.

### 도구 목록

| 도구 | 기능 |
|---|---|
| `teapot_status` | 허브 상태, 연결된 탭, 편집기 주소를 표시합니다. |
| `teapot_rules` | 티팟 HTML·JSX 작성 규칙을 반환합니다. |
| `teapot_list_checkpoints` | 저장본 목록을 표시합니다. |
| `teapot_overview` | 필드별 길이를 요약합니다. 본문을 제외하므로 토큰을 절약합니다. |
| `teapot_get` | 지정한 필드만 읽습니다. |
| `teapot_update` | 필드나 시작 상황 일부를 수정해 저장합니다. `save_as_new`를 지정하면 새 저장본으로 저장합니다. |
| `teapot_put_file` | 로컬 파일 내용을 저장본의 한 칸(JSX 코드, 가이드라인, 시작 메시지 등)에 그대로 넣고 저장합니다. 아래 [파일로 칸 채우기](#파일로-칸-채우기)를 참고합니다. |
| `teapot_pull` / `teapot_push` | 저장본을 `workspace/<캐릭터 ID>/` 폴더에 파일로 내려받고, 수정한 파일을 다시 저장합니다. |
| `teapot_reload_editor` | 티팟 제작창을 새로고침합니다. |

`characterId`와 `checkpointId`를 생략하면 현재 열려 있는 티팟 탭의 캐릭터와 저장본을 대상으로 합니다.

## 파일로 칸 채우기

긴 JSX 코드나 HTML 가이드라인을 대화창이나 편집기에 직접 옮겨 붙이면 일부가 빠지거나 바뀌는 실수가 생길 수 있습니다. **파일로 칸 채우기**는 로컬 파일 내용을 그대로 읽어 지정한 칸에 넣고 저장합니다.

- Claude Code에서는 `teapot_put_file` 도구를 사용합니다. 파일을 서버가 직접 읽으므로 내용이 대화를 거치지 않습니다.
- 명령줄에서는 다음과 같이 실행합니다. 허브가 실행 중이고 티팟 제작창이 열려 있어야 합니다.

  ```bash
  npm run put -- <파일> <kind> [name] [--field <칸>] [--dry-run] [--new <새 저장본 이름>]
  ```

| kind | 넣는 칸 | name / field |
|---|---|---|
| `jsx` | JSX 컴포넌트 코드 | name: 컴포넌트 이름 (생략하면 파일 이름) |
| `guideline` | 캐릭터 가이드라인 내용 | name: 제목 또는 `#번호` (없는 제목이면 새로 만듦) |
| `start_message` | 시작 메시지 | name: 시작 상황 이름 또는 `#번호` |
| `start_circumstance` | 시작 상황 설명 | name: 시작 상황 이름 또는 `#번호` |
| `start_addition` | 공용 프롬프트에 더하기 | name: 시작 상황, field: `prompt` / `worldview` / `secret` / `output_format` |
| `field` | 공용 프롬프트 칸 | field: `prompt` / `worldview` / `secret` / `output_format_prompt` / `recommended_answer_prompt` / `detail_description` |
| `status_template` / `status_constraint` | 상태창 템플릿 / 변수 제어 프롬프트 | — |

- 파일 끝의 빈 줄과 공백만 정리하며, 나머지 내용은 그대로 넣습니다.
- JSX는 티팟 보안 검증을 통과해야 저장되며, `compiled_hash`도 자동으로 갱신합니다. 같은 폴더에 `<이름>.meta.json`(display_name, description, trigger, keys, props)이 있으면 표시 이름·설명·props도 그 내용으로 맞추고, 저장본에 없는 컴포넌트는 새로 만듭니다.
- `--dry-run`(도구에서는 `dry_run`)을 지정하면 저장하지 않고 바뀔 글자 수만 확인합니다. 내용이 같으면 저장하지 않습니다.
- 저장 전 원본은 다른 저장 기능과 마찬가지로 `backups/`에 백업됩니다.

## 편집기 사용법

허브를 실행한 뒤 <http://127.0.0.1:18765/>를 엽니다. 티팟 캐릭터 제작창 탭이 하나 열려 있어야 하며, 최소화해도 됩니다.

### 화면 구성

- **왼쪽 목차**에서 항목을 선택하면 오른쪽에 해당 항목의 편집 화면만 표시됩니다.
  - **캐릭터 정보**: 제목, 한 줄 소개, 해시태그, 상세 설명을 한 화면에서 편집합니다. 캐릭터 가이드라인은 항목별로 편집합니다.
  - **공용 프롬프트**: 기본 정보, 세계관, 비밀, 출력 형식, 추천 답변 프롬프트, 예시대화, 로어북, JSX, UI(상태창·다인 채팅 등장인물), 직접 수정한 템플릿 문구
  - **시작 상황**: 시작 상황마다 이름·상황 설명·시작 메시지를 한 화면에서 편집하고, 추천 답변과 "공용 프롬프트에 더하기" 항목을 따로 편집합니다. "더하기" 화면에서는 공용 내용(읽기 전용)이 나란히 표시됩니다.
  - **기타**: 플레이어 노트, 페르소나, 커맨드, 상황 이미지(전체 카드 화면)
  - **설정**: 모델, 최대 출력 토큰, 장르, 대상, 공개 설정, 성인·댓글 옵션을 입력 칸과 선택 상자로 편집합니다. 모델은 목록에서 고르거나 직접 입력할 수 있습니다. 프롬프트 섹션 순서는 JSON으로 편집합니다.
- 목차 위의 검색칸(`Ctrl+Shift+F`)으로 항목 이름과 내용을 검색할 수 있습니다.
- 목록 폴더에 마우스를 올리면 **추가 / 복제 / 삭제** 버튼이, 목록 항목에는 **↑ ↓** 이동 버튼이 표시됩니다.

### 텍스트 편집

- 긴 텍스트는 줄 번호와 검색(`Ctrl+F`)을 지원하는 코드 편집기(CodeMirror)에서 편집합니다.
- 마크다운, HTML, JSX 코드는 GitHub 색상으로 구분하여 표시됩니다. `{user}`, `{char}`, `{{img::이름}}`도 강조 표시됩니다.
- JSX 코드를 수정하면 티팟과 같은 방식으로 `compiled_hash`를 다시 계산합니다.

### 미리보기

- 캐릭터 가이드라인과 시작 메시지는 오른쪽에 미리보기가 표시됩니다. 티팟과 같은 렌더링 규칙을 적용합니다.
- 미리보기에서 요소를 클릭하면, 그 요소를 만든 코드 줄로 이동합니다.
- 편집 칸과 미리보기 사이의 경계선을 끌어 두 영역의 너비를 조절할 수 있습니다. 조절한 너비는 기억되며, 경계선을 두 번 클릭하면 기본 너비로 돌아갑니다.
- 글꼴은 티팟과 같은 방식(Pretendard 가변 글꼴)으로 불러오므로 글자 굵기도 티팟과 같게 표시됩니다.
- 시작 메시지 미리보기에서는 `{char}`, `{user}`, `{{img::이름}}`을 실제 값으로 바꾸어 표시합니다. `{user}`에 들어갈 이름은 미리보기 상단에서 지정합니다.
- 시작 메시지 안의 JSX 호출(`<컴포넌트이름 prop="값" />` 또는 `{{jsx::컴포넌트이름|{...}}}`)은 실제 컴포넌트로 실행하여 표시합니다. 공용 JSX와 해당 시작 상황의 JSX +를 사용하며, 등록되지 않은 이름은 티팟과 같이 글자 그대로 표시됩니다.
- JSX 컴포넌트 편집 화면에서는 티팟과 같은 방식(보안 검증 → Babel 변환 → React 18 실행)으로 컴포넌트를 미리 실행합니다.
  - 미리보기 props에는 Props 정의의 예시값이 들어갑니다.
  - 보안 검증이나 문법 오류가 있으면 위치(줄:칸)를 표시하며, 누르면 해당 코드 줄로 이동합니다.
  - 미리보기에서는 `sendToChat`이 실제로 전송되지 않고 알림으로만 표시됩니다.
  - 미리보기에는 인터넷 연결이 필요합니다(React·Babel을 unpkg에서 불러옵니다).

### 분량 막대

화면 하단에 티팟 제작창과 같은 방식으로 계산한 프롬프트 분량이 표시됩니다.

- 구간별 글자 수, 총 글자 수, 입력 토큰 수, 정량제·종량제 구분을 표시합니다.
- 토큰 수는 티팟의 토큰 계산 API를 사용합니다.
- 계산 기준은 합산한 프롬프트가 가장 긴 시작 상황입니다.
- 상세 모드(템플릿 섹션을 사용하는 캐릭터)의 분량은 근사치입니다.

### 저장

- 변경된 항목에는 주황색 점이 표시됩니다. 항목마다 **되돌리기**를 사용할 수 있습니다.
- **저장**(`Ctrl+S`)은 다음 순서로 진행됩니다.
  1. 서버의 최신 저장본을 확인합니다. 그사이 다른 곳에서 저장되었다면 덮어쓸지 묻습니다.
  2. 저장합니다.
  3. 열려 있는 티팟 제작창을 새로고침합니다. 상단 체크박스로 이 동작을 끌 수 있습니다.
- **새 저장본으로**를 누르면 기존 저장본은 유지하고 새 저장본을 만듭니다.
- 심사 중이거나 등록이 완료된 저장본(✓ 표시)은 티팟이 덮어쓰기를 허용하지 않습니다. 이 경우 저장하면 새 저장본(`제목없음 N`)으로 저장됩니다.
- Claude가 저장하면 편집기가 자동으로 내용을 다시 불러옵니다. 편집 중인 내용이 있으면 덮어쓰지 않고 알림만 표시합니다.

### 지원하지 않는 기능

- 이미지 업로드(프로필, 미디어 관리)와 캐릭터 등록(발행)은 티팟에서 직접 진행해야 합니다.
- 템플릿 기본 문구(Core Instructions 등)는 편집기에 표시되지 않습니다. 직접 수정한 문구만 표시됩니다.
- 상황 이미지는 이름과 설명만 수정할 수 있습니다.
- JSX 보안 검증은 티팟 저장 시점에 이루어집니다. 코드를 크게 수정한 경우 티팟 JSX 편집기에서 한 번 확인하기를 권장합니다.
- `prompt_char_count`(요금제 판정용 글자 수)는 티팟이 등록 시 계산하므로 편집기와 Claude는 수정하지 않습니다.

## 에셋 스튜디오

편집기 상단의 **에셋 스튜디오** 탭에서 NovelAI로 이미지를 생성하고, 마음에 드는 결과를 저장합니다. 화면은 세 영역으로 구성됩니다.

| 영역 | 내용 |
|---|---|
| 왼쪽: 프롬프트 보관함 | 저장한 프롬프트를 폴더별로 표시합니다. 항목을 누르면 입력 영역에 불러옵니다. |
| 가운데: 입력 영역 | 긍정 프롬프트, 부정 프롬프트, 캐릭터별 긍정·부정 프롬프트(최대 6명), 생성 설정을 입력합니다. |
| 오른쪽: 결과 영역 | 생성 과정을 실시간으로 표시하고, 완성된 이미지와 생성 기록을 보여 줍니다. **생성** 버튼은 생성 기록 바로 위에 있습니다. |

### 처음 설정

1. NovelAI 웹사이트에서 **설정(⚙) → Account → Get Persistent API Token**을 눌러 API 키(`pst-`로 시작)를 발급합니다.
2. 에셋 스튜디오 오른쪽 위의 **⚙ 설정**을 누르고 API 키를 입력한 뒤 저장합니다.
   - API 키는 이 PC의 `config/settings.json`에만 저장되며, NovelAI 서버 외에는 전송되지 않습니다.
   - 같은 화면에서 이미지 저장 폴더와 실시간 보기(스트리밍) 사용 여부를 변경할 수 있습니다.
3. 설정이 끝나면 상단에 잔여 Anlas와 **V5 생성 한도**(Opus 구독 시)가 표시됩니다.
   - 한도는 남은 비율(%)로 표시되며, 추가 사용량(Usage Boost)이 있으면 `+N%`로 함께 표시됩니다.
   - 마우스를 올리면 하루 충전량을 확인할 수 있습니다. 한도를 모두 쓰면 Anlas가 차감됩니다.

### 지원 모델

| 모델 | 비고 |
|---|---|
| V5 Full / V5 Curated | 기본 모델입니다. **모드**(Anime / Furry)를 선택할 수 있습니다. Furry를 선택하면 NovelAI 웹과 같이 프롬프트 앞에 `fur dataset, `이 붙습니다. |
| V5 Full의 **Effort** | High(기본) 또는 Medium을 선택합니다. Medium은 Anlas와 생성 한도를 덜 소모하는 대신 14스텝, Euler Ancestral, Heavy UC로 고정되며 캐릭터별 부정 프롬프트를 사용하지 않습니다. |
| V4.5 Full / Curated, V4 Full / Curated, V3 Anime / Furry | 이전 모델입니다. 캐릭터 프롬프트는 V4 이상에서만 사용할 수 있습니다. |

### 이미지 생성

1. 프롬프트를 입력합니다. 캐릭터 프롬프트는 V4 이상 모델에서 사용할 수 있으며, **위치 직접 지정**을 켜면 캐릭터마다 화면 위치를 정할 수 있습니다.
2. **생성 설정**에서 모델, 크기, 스텝, 가이던스, 샘플러, 시드 등을 지정합니다.
   - 시드를 비우면 매번 무작위로 생성합니다.
   - **품질 태그 자동 추가**와 **UC 프리셋**은 NovelAI 웹과 같은 방식으로 프롬프트 뒤·부정 프롬프트 앞에 문구를 덧붙입니다. 덧붙는 문구는 화면에서 확인하고 수정할 수 있습니다.
   - **생성** 버튼 옆 표시는 Opus 구독 기준으로 Anlas가 차감되지 않는 설정(일반 해상도, 28스텝 이하, 1장)인지 알려 줍니다. V5는 이 범위에서도 생성 한도(%)를 사용하므로 **Opus 한도 사용**으로 표시됩니다.
3. 결과 영역의 **생성**(`Ctrl+Enter`)을 누릅니다. 생성 과정이 오른쪽에 실시간으로 표시되며, **취소**로 중단할 수 있습니다.

### 저장 위치

- 생성한 이미지는 자동으로 저장되지 않습니다. 결과 영역의 **저장** 버튼을 눌러야 저장됩니다.
  - 저장하지 않은 이미지는 생성 기록에 **미저장** 표시와 함께 표시되며, 허브가 실행되는 동안 최근 30장까지 보관됩니다.
- 저장한 이미지는 `assets/<저장 폴더>/<날짜>/<시각>_<시드>.png`로 저장됩니다. 저장 폴더를 비우면 날짜 폴더에 바로 저장됩니다.
- 프롬프트와 설정은 NovelAI가 PNG 파일 안에 기록하므로 별도 파일을 만들지 않습니다.
- 생성 기록에서 이미지를 선택한 뒤 **프롬프트 불러오기** 또는 **시드까지 불러오기**를 누르면 PNG에 기록된 입력값을 되살립니다.
- **폴더 열기**와 **파일 위치**는 탐색기에서 해당 위치를 엽니다.

### 프롬프트 보관함

- **+ 새로 저장**: 현재 입력값 전체를 이름과 폴더를 지정해 저장합니다.
- **보관함에 덮어쓰기**(`Ctrl+S`): 불러온 프롬프트를 현재 입력값으로 갱신합니다.
- 항목에 마우스를 올리면 **이름 변경 / 복제 / 삭제** 버튼이 표시됩니다.
- 보관함은 `config/prompts.json`에 저장됩니다. 입력 중인 내용은 브라우저에 자동 보관되므로 새로고침해도 유지됩니다.

## 업데이트

### 새 버전 알림

편집기를 열면 허브가 GitHub 저장소의 최신 버전 번호(`package.json`)를 확인합니다. 설치한 버전보다 새 버전이 있으면 편집기 상단 제목 옆에 **새 버전 … 이 있어요** 알림과 **지금 업데이트** 버튼이 표시됩니다.

- 확인은 6시간에 한 번만 이루어지며, 버전 번호가 적힌 파일을 읽기만 합니다. 사용자 정보는 전송하지 않습니다.
- 알림의 **×** 를 누르면 그 버전에 대한 알림은 다시 표시되지 않습니다.
- 확인을 끄려면 환경 변수 `TEAPOT_NO_UPDATE_CHECK=1`을 설정한 뒤 허브를 실행합니다.

### 버튼으로 업데이트 (권장)

알림의 **지금 업데이트** 버튼을 누르면 다음 순서로 자동 진행됩니다. 저장하지 않은 편집 내용이 있으면 먼저 저장하거나 되돌려야 합니다.

1. 허브가 GitHub에서 최신 파일을 내려받습니다. git으로 받은 폴더는 `git pull`로 받습니다.
2. 바뀌는 파일만 교체합니다. 교체하기 전의 파일은 `backups/_update/<시각>_v<이전 버전>/`에 보관됩니다.
3. 필요한 패키지 구성이 바뀐 경우에만 `npm install`을 다시 실행합니다.
4. 허브가 새 버전으로 다시 시작되고, 편집기 창이 자동으로 새로고침됩니다.

업데이트해도 `config/`(API 키·프롬프트 보관함), `workspace/`, `backups/`, `assets/`(생성 이미지), `node_modules/` 폴더는 건드리지 않습니다.

업데이트 후 확인할 사항:

- 유저스크립트가 바뀐 경우 편집기에 안내가 표시됩니다. <http://127.0.0.1:18765/teapot-agent.user.js>를 다시 열어 설치합니다.
- Claude Code를 사용 중이라면 Claude Code 세션을 다시 시작해야 바뀐 도구가 적용됩니다.
- 업데이트 후 허브는 별도 창 없이 실행됩니다. 종료는 기존과 같이 `stop-hub.bat` 또는 `npm run hub:stop`으로 합니다.

> 버전 0.3.0 이하에는 업데이트 버튼이 없습니다. 이 경우 아래의 직접 업데이트를 한 번 진행하면, 그다음부터 버튼을 사용할 수 있습니다.

### 직접 업데이트

1. 허브를 종료합니다(`stop-hub.bat` 또는 `npm run hub:stop`).
2. 새 버전을 받습니다.
   - **git으로 받은 경우**: `<설치 폴더>`에서 다음 명령을 실행합니다.

     ```bash
     git pull
     ```

   - **ZIP으로 받은 경우**: 새 ZIP을 내려받아 압축을 푼 뒤, 안의 파일을 `<설치 폴더>`에 덮어씁니다. 위의 유지되는 폴더는 지우지 않습니다.
3. 패키지 구성이 바뀌었을 수 있으므로 `<설치 폴더>`에서 다음 명령을 실행합니다. (`start-editor.bat`은 `node_modules`가 없을 때만 자동 설치하므로, 업데이트 후에는 직접 실행하는 것이 안전합니다.)

   ```bash
   npm install --omit=dev
   ```

4. 허브를 다시 실행합니다. 유저스크립트가 바뀐 경우 <http://127.0.0.1:18765/teapot-agent.user.js>를 다시 열어 설치합니다.
5. Claude Code를 사용 중이라면 Claude Code 세션을 다시 시작해야 바뀐 도구가 적용됩니다.

### 자동 업데이트 끄기

설치 폴더에 `.no-auto-update`라는 파일을 만들면 업데이트 버튼이 표시되지 않습니다. 코드를 직접 고쳐 쓰는 폴더에서 사용합니다. 새 버전 알림은 계속 표시됩니다.

## 주의 사항

- 다른 곳에서 저장한 뒤, 이전에 열어 둔 티팟 제작창에서 그대로 저장하면 변경 내용을 덮어씁니다. 티팟 탭을 새로고침한 뒤 저장해야 합니다.
- 이 도구는 티팟의 비공식 내부 API를 사용합니다. 티팟이 업데이트되면 동작하지 않을 수 있습니다.
- 포트는 `TEAPOT_BRIDGE_PORT` 환경 변수로 변경할 수 있습니다. 변경할 경우 유저스크립트의 `PORT` 값도 함께 변경해야 합니다.

## 개발

- 편집기 라이브러리(`editor/src/vendor.js`)를 수정한 경우 다음 명령으로 `editor/vendor.js`를 다시 빌드합니다. 개발용 패키지가 설치되어 있어야 합니다.

  ```bash
  npm run build:vendor
  ```

- 다음 명령으로 MCP 도구를 직접 호출해 테스트할 수 있습니다.

  ```bash
  node scripts/try.mjs '[["teapot_overview",{}]]'
  ```
